# 🧠 GenAI Python Code Review Agent

An AI-powered code review system that analyzes Python repositories, detects issues, and generates structured, actionable feedback using Large Language Models (LLMs) like GPT and Claude.

---

## 🚀 Overview

This project is designed to automate code reviews at scale by leveraging LLMs for deep code understanding, reasoning, and structured reporting.

Unlike traditional linters or static analysis tools, this agent provides:
- Context-aware feedback
- Semantic understanding of code
- Human-like review suggestions

---

## 🔍 Key Features

- 📂 **Repository-Level Analysis**
  - Processes multiple Python files across a project
  - Understands inter-file dependencies (WIP)

- 🧠 **LLM-Powered Code Review**
  - Detects:
    - Bugs & logical errors
    - Code smells & anti-patterns
    - Performance issues
    - Security risks

- 📝 **Structured Review Output**
  - Per-file detailed reports
  - Consolidated markdown summary

- ⚡ **Automated Pipeline**
  - Batch processing of repositories
  - Generates ready-to-share review reports
